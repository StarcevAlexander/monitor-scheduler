# RELIABILITY — чек-лист надёжности с diff-триггерами

Применять после изменений: выбрать пункты, чьи триггеры затронуты диффом, прогнать их. Повторяющийся инцидент (2+ разов) — повод добавить пункт, а не запоминать заново. Правила ревью по этому файлу читаются из main, не из фича-ветки.

| Триггер (затронуто в диффе) | Что проверить |
|---|---|
| Работа с WinAPI / мониторами (вкл/выкл, режимы) | Поведение при отключённом мониторе, спящем дисплее, RDP-сессии; повторный вызов не ломает состояние |
| `config.json` / схема конфига | Чтение `config.example.json`-совместимого конфига, отсутствующие/лишние поля, кривые значения — внятная ошибка, не паника |
| Расписание / таймеры | Переход через полночь, смена часов, пустое расписание, дубль интервалов |
| Логирование | Ротация/размер `monitors.log`, падение при недоступном диске не роняет процесс |
| CLI / вывод | Коды выхода при успехе и ошибках, вывод без паник с трейсами в спокойных сценариях |
| Сборка (`build.ps1`, Cargo) | Release-сборка чистая, `clippy` без новых предупреждений, версия в бинарнике актуальна |
| Коммит | Штамп `Verified:` по факту прогонов (cargo build/clippy/test + ручной сценарий на живых мониторах) |

Flaky-проверки не ретраить: root cause или удалить пункт с причиной.
