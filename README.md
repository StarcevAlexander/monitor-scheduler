# Monitor Scheduler

Программа сама выключает мониторы вечером и включает утром — по расписанию, которое вы задаёте. Компьютер при этом продолжает работать: гаснут только экраны.

За минуту до выключения программа показывает окно-предупреждение поверх всех окон. В нём можно отложить выключение на 15 минут, 30 минут, 1 час или 2 часа: за минуту до нового времени окно появится снова, и выключение можно отложить ещё раз. Кнопка OK просто закрывает окно, а если ничего не нажимать, оно исчезнет само, когда мониторы погаснут.

На рабочем столе появляется ярлык «Выключить мониторы»: двойной щелчок гасит экраны сразу.

Работает на Windows 10/11 и macOS.

## Как пользоваться

### Windows

**1. Скачайте программу.** Откройте страницу [последнего релиза](https://github.com/StarcevAlexander/monitor-scheduler/releases/latest) и нажмите на файл `monitors.exe`.

**2. Положите её в постоянную папку.** Например, создайте папку `Мониторы` в «Документах» и перенесите туда `monitors.exe` из «Загрузок». Не запускайте программу прямо из «Загрузок»: рядом с ней появятся её настройки, и папка должна остаться на месте.

**3. Запустите.** Дважды щёлкните по `monitors.exe`. Если появится синее окно «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»: программа не подписана, это нормально.

Никакого окна не откроется — программа работает незаметно. Понять, что она запустилась, можно по двум новым файлам в папке: `config.json` (расписание) и `monitors.log` (журнал).

По умолчанию мониторы гаснут в 23:00 и включаются в 08:00 каждый день.

**4. Включите автозапуск,** чтобы программа работала и после перезагрузки:

1. Откройте папку с программой.
2. Щёлкните по адресной строке вверху окна папки, сотрите текст, напечатайте `cmd` и нажмите Enter. Откроется чёрное окно.
3. Напечатайте `monitors.exe install` и нажмите Enter.

Заодно на рабочем столе появится ярлык «Выключить мониторы». Если программа у вас уже была установлена раньше, повторите этот шаг после обновления, чтобы ярлык появился.

Там же можно проверить, что экраны гаснут: напечатайте `monitors.exe off` и нажмите Enter. Через секунду мониторы погаснут; чтобы включить их, нажмите любую клавишу на клавиатуре. А `monitors.exe warn` покажет окно-предупреждение, которое появляется за минуту до выключения.

### Mac

**1. Узнайте, какой у вас Mac.** Нажмите на значок яблока в левом верхнем углу экрана → «Об этом Mac». Если в строке «Чип» написано Apple M1, M2, M3 или новее — вам нужен файл `monitors-mac-arm64`. Если написано «Процессор … Intel» — `monitors-mac-amd64`.

**2. Скачайте нужный файл** со страницы [последнего релиза](https://github.com/StarcevAlexander/monitor-scheduler/releases/latest).

**3. Откройте Терминал:** нажмите Cmd + Пробел, напечатайте «Терминал» и нажмите Enter.

**4. Установите программу.** Скопируйте строку ниже целиком, вставьте в Терминал и нажмите Enter. Для Mac на Intel замените в ней `arm64` на `amd64`.

```sh
mkdir -p ~/Applications/monitors && mv ~/Downloads/monitors-mac-arm64 ~/Applications/monitors/monitors && cd ~/Applications/monitors && chmod +x monitors && xattr -c monitors
```

**5. Включите программу и автозапуск** — ещё одна строка:

```sh
~/Applications/monitors/monitors install && launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.starcevalexander.monitor-scheduler.plist
```

Готово: программа работает в фоне и будет запускаться сама после каждого входа в систему. На рабочем столе появится файл «Выключить мониторы»: двойной щелчок по нему гасит экраны (при этом откроется окно Терминала, его можно закрыть). По умолчанию мониторы гаснут в 23:00 и включаются в 08:00 каждый день.

Проверить, что экраны гаснут: `~/Applications/monitors/monitors off`.

### Как поменять расписание

Откройте файл `config.json` из папки с программой в любом текстовом редакторе: на Windows — правой кнопкой → «Открыть с помощью» → «Блокнот», на Mac — командой `open -e ~/Applications/monitors/config.json` в Терминале.

Внутри будет примерно так:

```json
{
  "rules": [
    { "action": "off", "time": "23:00" },
    { "action": "on", "time": "08:00" }
  ]
}
```

- `"off"` — выключить мониторы, `"on"` — включить.
- `"time"` — время в формате часы:минуты, например `"22:30"`.
- Чтобы правило срабатывало только в некоторые дни, добавьте список дней: `"days": ["mon", "tue", "wed", "thu", "fri"]` — это будни. Дни: `mon` пн, `tue` вт, `wed` ср, `thu` чт, `fri` пт, `sat` сб, `sun` вс.

Например, выключать в 23:00 каждый день, а включать в 08:00 по будням и в 10:00 по выходным:

```json
{
  "rules": [
    { "action": "off", "time": "23:00" },
    { "action": "on", "time": "08:00", "days": ["mon", "tue", "wed", "thu", "fri"] },
    { "action": "on", "time": "10:00", "days": ["sat", "sun"] }
  ]
}
```

Сохраните файл — программа подхватит изменения сама, перезапускать ничего не нужно. Следите за кавычками и запятыми между правилами: если файл испорчен, программа продолжит работать по старому расписанию и запишет ошибку в `monitors.log`.

### Как удалить

**Windows:** в чёрном окне из шага 4 напечатайте `monitors.exe uninstall` и нажмите Enter. Затем откройте Диспетчер задач (Ctrl + Shift + Esc), найдите `monitors.exe` → «Снять задачу» и удалите папку с программой.

**Mac:** вставьте в Терминал:

```sh
launchctl bootout gui/$(id -u)/com.starcevalexander.monitor-scheduler; ~/Applications/monitors/monitors uninstall && rm -rf ~/Applications/monitors
```

### Если что-то не так

- **Мониторы не гаснут.** Некоторые мониторы не реагируют на системную команду сна. Откройте `monitors.log` и [создайте issue](https://github.com/StarcevAlexander/monitor-scheduler/issues), приложив его содержимое.
- **Экраны снова включились сами.** Их разбудило движение мыши или нажатие клавиши. Повторно программа погасит их только по следующему правилу `off`.
- **Ничего не произошло в назначенное время.** Если компьютер в этот момент спал или был выключен, пропущенное действие не выполняется.
- **На Mac после включения экранов просит пароль.** Так работает защита macOS после сна дисплея; отключается в Настройках → «Экран блокировки».

## Для разработчиков

### Как это работает

- **Windows.** Выключение — системный сигнал `SC_MONITORPOWER`. Включение — тот же сигнал плюс микродвижение мыши. Автозапуск — ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- **macOS.** Выключение — `pmset displaysleepnow`. Включение — `caffeinate -u -t 1`. Автозапуск — `~/Library/LaunchAgents/com.starcevalexander.monitor-scheduler.plist`.

За минуту до каждого правила `off` показывается предупреждение: на Windows — собственное окно WinAPI поверх всех окон с кнопками отсрочки, на macOS — `display dialog` через `osascript` с кнопкой «Отложить…» и списком вариантов. Окно закрывается само в момент выключения. Отложенное выключение — разовое, оно хранится только в памяти программы и не переживает её перезапуск.

Ярлык на рабочем столе создаёт команда `install`: на Windows — `Выключить мониторы.lnk` (через `WScript.Shell`), на macOS — `Выключить мониторы.command`. Оба запускают `monitors off`.

Программа проверяет расписание каждые 15 секунд, перечитывает `config.json` при изменении и не даёт запустить второй экземпляр. Вывод пишется в `monitors.log` рядом с бинарником.

### Сборка

На Windows:

```powershell
./build.ps1
```

Получится `monitors.exe` без консольного окна и две версии для macOS: `monitors-mac-arm64` и `monitors-mac-amd64`.

На Mac с установленным Go:

```sh
go build -o monitors .
```

### Команды

| Команда | Что делает |
|---|---|
| `monitors` или `monitors run` | запускает планировщик |
| `monitors off` | выключить мониторы сейчас (через 1 секунду) |
| `monitors on` | включить мониторы сейчас |
| `monitors warn` | показать предупреждение о выключении (то же окно, что за минуту до правила `off`; выбор отсрочки только пишется в журнал) |
| `monitors install` | добавить планировщик в автозапуск текущего пользователя и ярлык «Выключить мониторы» на рабочий стол |
| `monitors uninstall` | убрать из автозапуска и удалить ярлык |
