# Monitor Scheduler

Фоновая утилита для Windows: выключает и включает все мониторы по расписанию.

Выключение — системный сигнал `SC_MONITORPOWER` (мониторы уходят в режим энергосбережения, ПК продолжает работать). Включение — тот же сигнал плюс микродвижение мыши.

## Сборка

```powershell
./build.ps1
```

Получится `monitors.exe` без консольного окна.

## Команды

| Команда | Что делает |
|---|---|
| `monitors.exe` или `monitors.exe run` | запускает планировщик в фоне |
| `monitors.exe off` | выключить мониторы сейчас (через 1 секунду) |
| `monitors.exe on` | включить мониторы сейчас |
| `monitors.exe install` | добавить планировщик в автозапуск текущего пользователя |
| `monitors.exe uninstall` | убрать из автозапуска |

Вывод пишется в `monitors.log` рядом с exe.

## Расписание

`config.json` рядом с exe (создаётся при первом запуске, пример — `config.example.json`):

```json
{
  "rules": [
    { "action": "off", "time": "23:00" },
    { "action": "on", "time": "08:00", "days": ["mon", "tue", "wed", "thu", "fri"] }
  ]
}
```

- `action` — `off` или `on`
- `time` — `HH:MM`, местное время
- `days` — необязательно: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`; без поля правило работает каждый день

Изменения в `config.json` подхватываются на лету, перезапуск не нужен.

## Ограничения

- Мониторы проснутся от движения мыши или нажатия клавиши; повторно сами не гаснут до следующего правила `off`.
- Если ПК спал во время правила, пропущенное действие не выполняется задним числом.
- Запущен может быть только один планировщик.
- Остановить: Диспетчер задач → `monitors.exe` → Снять задачу.
